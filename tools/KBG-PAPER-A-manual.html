01이 프로그램은 무엇인가

KBG PAPER_A는 설문조사 데이터로 PLS 구조방정식(PLS-SEM) 분석을 하는 프로그램입니다. "직무스트레스가 소진을 높이고, 소진이 이직의도를 높인다"처럼 변수들 사이의 인과 경로를 화살표 모형으로 그려 검증하는 분석법으로, SmartPLS나 R 같은 전문 도구가 하던 일을 클릭 몇 번으로 대신합니다.

버튼 한 번에 나오는 것들:

  • 연구모형 그림(경로계수·유의성 별표·R² 포함, PNG 저장 가능)
  • 측정모형 평가 — 외부적재량, Cronbach α, CR, AVE
  • 판별타당도 — Fornell-Larcker, HTMT
  • 구조모형 — 부트스트랩 경로계수(t, p, 95% 신뢰구간), R², f², VIF, Q²
  • 매개효과(간접효과 분해), 조절효과(심플 슬로프), 다집단 분석(순열검정)
  • 논문에 바로 붙일 수 있는 국문 결과 서술 초안
이 프로그램은 서버가 없습니다. 모든 계산이 여러분 컴퓨터의 브라우저 안에서만 실행되며, 설문 데이터는 인터넷으로 단 한 바이트도 전송되지 않습니다. 인터넷이 끊긴 상태에서도 작동합니다(글꼴만 기본체로 바뀝니다).

02여는 방법과 화면 구성

설치가 없습니다. KBG-PAPER-A.html 파일을 더블클릭하면 크롬·엣지 등 브라우저에서 바로 열립니다. 즐겨찾기에 추가해 두면 프로그램 아이콘처럼 쓸 수 있습니다.

화면은 좌우 둘로 나뉩니다.

  • 왼쪽 — 설정 패널: 위에서 아래로 ① 데이터 → ② 잠재변수 → ③ 경로 → ④ 실행. 번호 순서대로만 진행하면 됩니다.
  • 오른쪽 — 결과 화면: 분석이 끝나면 모형도부터 결과 서술까지 8개 탭이 나타납니다.

화면 맨 위의 프로젝트 저장을 누르면 데이터+모형 설정이 파일 하나로 저장되고, 다음에 프로젝트 열기로 이어서 작업할 수 있습니다.

033분 빠른 시작

처음이라면 내 데이터를 넣기 전에, 내장된 예제로 전체 흐름을 한 번 겪어보는 것이 가장 빠릅니다.

  1. 예제 데이터 불러오기① 데이터에서 예제 데이터를 클릭합니다. 사회복지사 250명의 가상 설문(직무스트레스·사회적지지·소진·이직의도, 성별)이 들어옵니다.
  2. 잠재변수 자동 구성② 잠재변수에서 문항 이름으로 자동 구성을 클릭합니다. JS1~JS4, BO1~BO3처럼 이름이 붙은 문항들이 자동으로 묶여 JS·SS·BO·TI 네 개의 잠재변수가 만들어집니다.
  3. 경로 3개 추가③ 경로에서 드롭다운으로 JS → BO, SS → BO, BO → TI를 하나씩 추가합니다.
  4. 조절효과와 다집단 (선택)조절효과에서 JS × SS → BO를 추가하고, 다집단 분석에서 집단 변수로 성별을 고릅니다.
  5. 분석 실행분석 실행 — 한 번에 전부를 클릭합니다. 부트스트랩 500회 기준 5~10초 뒤 오른쪽에 결과 탭이 모두 나타납니다.

여기까지 되면 끝입니다. 내 데이터로 할 일도 이 다섯 단계와 완전히 같습니다.

041단계 — 데이터 준비

데이터가 갖춰야 할 모양

  • 첫 줄은 변수명, 둘째 줄부터 응답자 한 명이 한 줄.
  • 측정문항은 숫자(리커트 1~5, 1~7 등). 빈 칸(결측)이 있는 응답자는 분석에서 자동 제외되고 몇 명이 빠졌는지 알려줍니다.
  • 문항 이름은 "개념약자+번호"를 권장 — 예: BO1, BO2, BO3. 이렇게 지으면 잠재변수를 자동으로 묶어줍니다.

불러오는 세 가지 방법

방법이럴 때하는 법
엑셀 붙여넣기 (가장 쉬움)데이터가 엑셀에 있을 때엑셀에서 변수명 줄부터 범위를 복사(Ctrl+C) → 붙여넣기 클릭 → 붙여넣은 뒤 불러오기
CSV 파일CSV로 저장된 파일이 있을 때CSV 파일 열기 → 파일 선택 (쉼표·탭·세미콜론 구분 자동 인식)
예제 데이터연습할 때예제 데이터 클릭
.xlsx를 파일로 직접 여는 기능은 없습니다. 대신 엑셀에서 복사 → 붙여넣기가 완전히 같은 역할을 하며 오히려 더 빠릅니다. 원하는 범위만 골라 넣을 수 있다는 장점도 있습니다.

052단계 — 잠재변수 만들기

잠재변수는 여러 문항이 함께 재는 하나의 개념입니다(예: BO1~BO3 세 문항 → "소진"). 만드는 방법은 두 가지입니다.

방법 A — 자동 구성 (권장)

문항 이름으로 자동 구성을 누르면 "같은 이름+연속 번호" 문항들이 자동으로 묶입니다. JS1 JS2 JS3 → 잠재변수 JS. 이름 뒤에 _1, -1처럼 붙어 있어도 인식합니다.

방법 B — 직접 선택

이름 칸에 잠재변수 이름(예: 소진)을 쓰고, 아래 문항 칩을 클릭해 선택한 뒤 추가. 선택된 칩은 이렇게 바뀝니다: BO1 BO2 BO3 TI1 TI2

  • 이미 다른 잠재변수에 속한 문항은 흐리게 표시되고 다시 쓸 수 없습니다.
  • 잘못 만들었으면 목록의 ×로 지우고 다시 만들면 됩니다.
  • 문항은 잠재변수당 3개 이상을 권장합니다(2개도 가능하지만 신뢰도 평가가 약해집니다).

063단계 — 경로·조절·다집단

경로 (필수)

가설 하나가 화살표 하나입니다. "A가 B에 영향을 준다"면 드롭다운에서 A → B를 고르고 추가. 원인→결과가 돌고 도는 순환 구조(A→B→A)는 PLS에서 허용되지 않아 자동으로 막아줍니다.

조절효과 (선택)

"W가 강할수록 A→B 효과가 달라진다"는 가설이면 A × W → B를 추가합니다. 필요한 주효과 경로(A→B, W→B)가 없으면 자동으로 넣어줍니다. 결과는 조절효과 탭에서 상호작용항 유의성과 심플 슬로프(저·중·고 집단 기울기 그래프)로 확인합니다.

다집단 분석 (선택)

성별처럼 집단을 나누는 변수를 고르면, 가장 빈도가 높은 두 집단으로 나눠 모든 경로계수가 집단 간에 다른지 순열검정으로 비교합니다. "남녀 간에 경로가 다른가?"라는 가설이 있을 때만 사용하면 됩니다.

074단계 — 분석 실행

옵션의미권장
부트스트랩 횟수경로계수의 유의성(t, p, 신뢰구간)을 계산하기 위한 반복 재표집 횟수. 많을수록 안정적이고 오래 걸립니다.연습 100 · 논문 제출용 1000~2000
순열 횟수다집단 분석에서 집단 차이의 p값을 만드는 반복 횟수.연습 100 · 논문 500

분석 실행 — 한 번에 전부를 누르면 진행 막대가 차오르고, 끝나면 "분석 완료 — n=…, 부트스트랩 …회" 메시지와 함께 오른쪽에 결과가 나타납니다. 예제 규모(문항 13개, n=250, 부트스트랩 500회)에서 10초 안팎입니다.

08결과 탭 읽는 법

탭은 논문의 결과 장 순서와 같습니다. 왼쪽에서 오른쪽으로 읽으면 그대로 논문 순서가 됩니다. 모든 표 아래에는 해석 상자가 붙어 있어 그 표가 기준을 충족했는지 문장으로 알려줍니다.

10결과를 논문으로 옮기기

표 옮기기 — 복사 버튼

모든 표 제목 옆의 복사를 누른 뒤 HWP(한글)나 Word에 Ctrl+V 하면 표 형태 그대로 붙습니다. 붙인 뒤 학교 양식(줄 간격·괘선)에 맞게 다듬기만 하면 됩니다.

글 옮기기 — 결과 서술 탭

결과 서술 탭의 서술 전체 복사는 측정모형 평가부터 다집단까지, 실제 분석 수치가 들어간 국문 문단을 통째로 복사합니다. 초안일 뿐이므로 반드시 연구 맥락에 맞게 다듬고, 수치가 표와 일치하는지 확인한 뒤 사용하세요.

파일로 내보내기

  • 전체 결과 → Excel — 모든 표를 시트별로 담은 엑셀 파일
  • 전체 결과 → Word — 표와 해석을 담은 워드 문서
  • 모형도 탭의 PNG로 저장 — 논문 삽입용 고해상도 모형 그림
  • 프로젝트 저장 — 데이터+설정 전체를 저장했다가 나중에 이어서 분석
클로드 아티팩트 링크로 열었을 때는 보안 정책상 파일 다운로드(Excel·Word·PNG·프로젝트 저장)가 작동하지 않습니다. 표 복사와 서술 복사는 됩니다. 내보내기가 필요하면 컴퓨터에 저장된 KBG-PAPER-A.html 파일을 여세요 — 그쪽이 완전판입니다.

11자주 묻는 질문·문제 해결

Q. 표본이 몇 명이면 되나요?
결측 제외 후 30명 미만이면 실행이 거부됩니다. 관례적으로는 가장 화살표를 많이 받는 변수의 화살표 수 × 10명 이상(10-times rule)을 최소로 보고, 100명 이상을 권장합니다.
Q. 적재량이 빨간색(낮음)으로 나옵니다.
그 문항이 개념을 잘 재지 못한다는 뜻입니다. 0.4 미만이면 잠재변수에서 그 문항을 ×로 빼고 다시 실행해 보세요. 0.4~0.708이면 α·CR·AVE가 기준을 충족하는지 보고 유지 여부를 결정합니다.
Q. "순환(고리)이 생깁니다"라며 경로가 추가되지 않습니다.
A→B와 B→A를 동시에 넣을 수 없습니다. 이론적으로 더 우선하는 방향 하나만 남기세요.
Q. 결과가 나오다 말고 "수렴하지 않았습니다"라고 합니다.
드문 경우로, 문항 수가 너무 적거나(1개짜리 잠재변수) 데이터에 변산이 거의 없는 문항이 섞였을 때 생깁니다. 문항 구성을 확인하세요.
Q. 실행할 때마다 p값이 조금씩 다른가요?
아니요. 부트스트랩 시드가 고정되어 있어 같은 데이터·같은 설정이면 항상 같은 결과가 나옵니다. 재현성 걱정 없이 논문에 쓸 수 있습니다.
Q. 한글이 깨져 보입니다.
CSV가 다른 인코딩으로 저장된 경우입니다. 엑셀에서 "CSV UTF-8"로 다시 저장하거나, 그냥 엑셀에서 복사→붙여넣기를 쓰세요(붙여넣기는 인코딩 문제가 없습니다).
Q. 데이터가 외부로 나가지 않는다는 걸 어떻게 믿나요?
인터넷을 끊고 실행해 보세요. 그래도 분석이 완전히 작동합니다. 서버 통신 자체가 없는 단일 HTML 파일입니다.

12알아두어야 할 한계

정직하게 쓰기 위해 알아둘 세 가지입니다. 논문 방법론 절이나 심사 답변에서 그대로 언급하면 됩니다.

  • Q²는 근사값입니다. blindfolding의 재추정 단계를 생략한 redundancy 방식이라 SmartPLS 수치와 소수점 차이가 날 수 있습니다. 화면 하단에도 명시되어 있습니다.
  • 다집단 분석에 MICOM(측정 동일성 검증)이 포함되지 않습니다. 집단 비교를 본격적 가설로 다루는 논문이라면 이 점을 한계로 언급하는 것이 안전합니다.
  • 반영지표(Mode A) 전용입니다. 조형지표(formative) 측정모형은 지원하지 않습니다.
