paper-toolkit 설치 안내

논문 도구 묶음(paper-toolkit.zip)을 내 PC에 설치하는 절차입니다. 자동 설치 스크립트가 대부분을 처리하고, 스크립트가 못 하는 몇 가지만 손으로 마무리합니다. 전체 30분 안팎(프로그램 다운로드 시간 포함).

① 자동 · 5분ZIP 풀기 → install.ps1
② 자동 · 10분winget·pip·MCP (인터넷)
③ 수동 · 3분Claude Code에서 /plugin 3건
④ 수동 · 10분Ghostscript·Zotero 확장 등
⑤ 확인 · 2분/paper-writing-order 작동

★가장 빠른 길 — GitHub 플러그인으로 설치

ZIP 없이도 됩니다. 스킬·에이전트는 GitHub 저장소 sk01020432947-oss/paper-toolkit가 Claude Code 플러그인 마켓플레이스로 등록돼 있어, Claude Code 안에서 두 줄이면 끝납니다. ZIP은 인터넷이 안 되거나 라이선스 미확인 스킬 4종까지 필요할 때만 쓰세요.

① Claude Code 안에서

/plugin marketplace add sk01020432947-oss/paper-toolkit
/plugin install paper-toolkit@paper-toolkit

또는 Claude Code에게 말로: "sk01020432947-oss/paper-toolkit 마켓플레이스 추가하고 paper-toolkit 플러그인 설치해줘". 설치 후 Claude Code 재시작 → /paper-writing-order 확인.

② 프로그램·MCP까지 (선택)

Zotero·Obsidian·Pandoc·OCR·pip·HWP MCP는 플러그인에 안 들어가므로 저장소의 install.ps1을 -SkipSkills로 실행합니다. Claude Code에게 시켜도 됩니다: "github.com/sk01020432947-oss/paper-toolkit clone해서 install.ps1 -SkipSkills 실행해줘"

git clone https://github.com/sk01020432947-oss/paper-toolkit
cd paper-toolkit
powershell -ExecutionPolicy Bypass -File .\install.ps1 -SkipSkills

그 다음은 아래 4단계(ARS·deep-research 플러그인)와 5~6단계(수동 설치·API 키)로 이어집니다. 1~3단계는 ZIP 방식일 때만 해당합니다.

GitHub 저장소에는 라이선스가 확인된 스킬 15종만 들어 있습니다. ZIP에만 있는 것: hwpxskill · kosis-stats · public-data-finder · national-assembly-tracker · deep-research-pro · deep-interview (원 출처 링크는 저장소 README 참고).

항목필수 여부확인 방법
Windows 10/11 + PowerShell 5.1 이상필수시작 메뉴에서 "PowerShell" 검색. Windows 기본 내장
Claude Code CLI (로그인된 상태)필수터미널에서 claude --version. 없으면 docs.anthropic.com/claude-code에서 설치
winget (앱 설치 관리자)권장winget --version. Windows 11은 기본 내장, 없으면 Microsoft Store에서 "앱 설치 관리자"

관리자 권한불필요모든 설치는 사용자 폴더 안에서 이뤄짐(winget 일부는 UAC 창이 뜰 수 있음)

01ZIP 풀기

위치는 아무 곳이나 괜찮지만, 경로에 한글·공백이 없는 곳이 안전합니다.

① paper-toolkit.zip 우클릭 → 압축 풀기 (예: C:\paper-toolkit\)

② 풀린 폴더 안에 다음이 보이면 정상:

paper-toolkit\
├─ install.ps1                  ← 설치 스크립트
├─ README.md
├─ paper-toolkit-inventory.html ← 도구 목록·소개 (먼저 훑어보길 권장)
├─ INSTALL-GUIDE.html           ← 이 문서
├─ skills\   (21개 폴더)        ← Claude Code 스킬
├─ agents\   (7개 .md)          ← humanize 에이전트
├─ tools\    (HTML 2개)         ← PLS-SEM 분석기 + 매뉴얼
└─ pandoc\   (4개)              ← md→docx Zotero 인용 변환 설정
다운로드한 ZIP이 "차단됨" 상태면 스크립트 실행이 막힐 수 있습니다. ZIP 파일 우클릭 → 속성 → 하단 "차단 해제" 체크 → 확인 후 압축을 푸세요.

02install.ps1 실행

풀린 폴더에서 PowerShell을 열고 한 줄 실행하면 됩니다.

폴더에서 PowerShell 열기

탐색기에서 paper-toolkit 폴더를 연 뒤, 주소창에 powershell 입력 → Enter. (또는 빈 곳 Shift+우클릭 → "PowerShell 창 여기서 열기")

실행

powershell -ExecutionPolicy Bypass -File .\install.ps1

-ExecutionPolicy Bypass는 이 한 번의 실행에만 적용되며 시스템 설정을 바꾸지 않습니다. pwsh 7이 있으면 pwsh로 바꿔도 됩니다.

옵션 (필요할 때만)

옵션뜻언제
-SkipWinget프로그램 설치 단계 건너뜀Zotero·Obsidian·Pandoc 등이 이미 있거나 직접 설치하고 싶을 때
-SkipPipPython 패키지 건너뜀Python을 따로 관리할 때
-SkipMcpMCP 등록 건너뜀Claude Code 설치 전에 먼저 파일만 복사할 때
-Force같은 이름의 기존 스킬·에이전트를 덮어씀재설치·업데이트할 때
-WithDissertationSimulator박사논문 시뮬레이터를 git clone까지58 에이전트 워크스페이스도 쓸 때 (약 수십 MB)
# 예: 프로그램은 내가 깔았으니 스킬·MCP만, 기존 것 덮어쓰기
powershell -ExecutionPolicy Bypass -File .\install.ps1 -SkipWinget -Force

스크립트가 하는 일 6단계자동

  1. 스킬 21개 → ~\.claude\skills\ 복사. 이미 있는 이름은 건너뜀(-Force 시 덮어씀). 복사하면서 원 제작자 PC 경로(%USERPROFILE%)를 내 계정 경로로 자동 치환
  2. 에이전트 7개 → ~\.claude\agents\
  3. 분석기·Pandoc 설정·목록 HTML → 문서\paper-toolkit\
  4. winget: Zotero · Obsidian · Pandoc · Tesseract-OCR · PDF24 · Python 3.12 · Git · Node.js LTS — 설치된 건 자동 건너뜀
  5. pip 13종: ocrmypdf · markitdown · pyalex · habanero · arxiv · pymupdf · pypdf · pypdfium2 · pandas · scipy · networkx · ruamel.yaml · master-of-hwp
  6. MCP 4종 claude mcp add: kordoc · korean-law · mohwp · public-data-lens
4단계에서 Python·Node를 처음 설치한 경우 PATH가 현재 창에 아직 반영되지 않아 5·6단계가 "python 없음"/"npx 없음"으로 실패할 수 있습니다. 그럴 땐 PowerShell 창을 닫고 새로 연 뒤 -SkipWinget으로 한 번 더 실행하세요.

04플러그인 3건 설치Claude Code 안에서

플러그인은 PowerShell이 아니라 Claude Code 대화창에서 슬래시 명령으로 설치합니다. 스크립트 마지막 출력에도 같은 명령이 있습니다.

아무 폴더에서 claude를 실행한 뒤 아래 6줄을 차례로 입력:

/plugin marketplace add sk01020432947-oss/claude-paper-skills
/plugin install paper-skills@claude-paper-skills

/plugin marketplace add Imbad0202/academic-research-skills
/plugin install academic-research-skills

/plugin marketplace add fivetaku/gptaku_plugins
/plugin install deep-research

academic-research-skills (ARS)/ars-plan /ars-outline /ars-full /ars-lit-review /ars-citation-check /ars-reviewer /ars-revision-coach 등 16개 명령 + 스킬 4종

설치 후 Claude Code를 한 번 종료했다가 다시 실행해야 스킬과 명령이 목록에 나타납니다.

05수동 설치 항목직접

winget·pip에 없거나 GUI 설치가 필요한 것들. 쓰지 않을 도구는 건너뛰어도 됩니다.

Ghostscript — OCRmyPDF가 필요로 함 OCR 쓸 때

github.com/ArtifexSoftware/ghostpdl-downloads/releases → gs10xxw64.exe 다운로드 → 설치. 설치 후 새 터미널에서 ocrmypdf --version이 나오면 끝.

Umi-OCR (포터블) GUI 일괄 OCR

github.com/hiroi-sora/Umi-OCR/releases → Umi-OCR_Paddle_*.7z → 아무 폴더에 풀고 Umi-OCR.exe 실행. 한국어 모델 내장. UI 한국어는 없으니 설정에서 English 권장.

Zotero 확장 2종 서지관리 핵심

  1. Better BibTeX: releases에서 최신 .xpi 다운로드
  2. Zotmoov: releases에서 .xpi 다운로드
  3. Zotero → 도구 → 플러그인 → 톱니바퀴 → Install Plugin From File → xpi 선택 → Zotero 재시작
  4. Better BibTeX 설정에서 citekey 공식 예: auth.lower + shorttitle(3,3) + year

Obsidian 커뮤니티 플러그인 4종 문헌노트

Obsidian → 설정 → 커뮤니티 플러그인 → 탐색에서 검색·설치·활성화: Zotero Integration · Templater · Pandoc Reference List · Copy Block Link.

Zotero Integration 설정 → Import Formats에 "논문 가져오기" 추가 → 템플릿 파일로 문서\paper-toolkit\pandoc\Template_literature-note-Zotero.md를 볼트 안에 복사해 지정. 하이라이트 색상 CSS는 zotero-highlights.css를 볼트의 .obsidian\snippets\에 넣고 활성화.

Pandoc 변환용 서지 파일 md→docx 인용

Zotero에서 My Library 우클릭 → Export Library → 형식 "Better CSL YAML" → Keep updated 체크 → 문서\paper-toolkit\pandoc\My Library.yaml로 저장. 그 뒤:

pwsh -File "$env:USERPROFILE\Documents\paper-toolkit\pandoc\convert.ps1" "내원고.md"
# → 다운로드\내원고.docx  (Word에서 Zotero 탭 Refresh 하면 살아있는 인용)

한컴오피스 상용 · 선택

HWP 최종 조판이 필요한 경우에만. kordoc·mohwp MCP는 한컴 없이도 HWPX 읽기·변환·편집이 됩니다.

06API 키·경로 설정

자료 수집 스킬은 공공 API 키가 있어야 작동합니다. 쓸 것만 발급받으세요(모두 무료).

스킬환경변수발급처
kosis-statsKOSIS_API_KEYkosis.kr/openapi 회원가입 → 인증키 발급
public-data-finderDATA_GO_KR_KEYdata.go.kr 마이페이지 → 인증키
national-assembly-tracker스킬 SKILL.md 참조open.assembly.go.kr 인증키
korean-law (MCP)LAW_OCopen.law.go.kr OC(이메일 ID). 기본값 test로도 제한적 조회 가능
zotero 스킬 (선택)KCI_API_KEYdata.go.kr "KCI 논문정보서비스" 개발계정(자동승인)
# 환경변수 영구 등록 예 (새 터미널부터 적용)
[Environment]::SetEnvironmentVariable('KOSIS_API_KEY','발급받은키','User')

경로 확인 2건

  • zotero 스킬: Zotero 데이터 폴더를 ~\Zotero(기본값)로 가정합니다. Zotero 설정 → 고급 → 파일 및 폴더에서 위치가 다르면 스킬 호출 시 --data-dir "경로"를 붙이거나 SKILL.md 상단 안내대로 수정.
  • wiki-recall · weekly-review: 원 제작자의 옵시디언 볼트 구조에 묶여 있습니다. 쓰려면 ~\.claude\skills\wiki-recall\SKILL.md 안의 볼트 경로를 본인 볼트로 바꾸고, 안 쓰면 두 폴더를 지워도 됩니다.

07설치 확인

아래가 모두 통과하면 설치 끝입니다.

  • Claude Code에서 /paper-writing-order 입력 시 스킬이 발동한다 (또는 "논문이 안 써져요"라고 말해본다)
  • /ars-plan, /humanize, /deep-research 명령이 자동완성에 뜬다
  • PowerShell claude mcp list에 kordoc · korean-law · mohwp · public-data-lens 가 보인다
  • python -c "import pyalex, habanero, fitz" 가 오류 없이 끝난다
  • pandoc --version, ocrmypdf --version(Ghostscript 설치 후), tesseract --list-langs에 kor 포함
  • Zotero 도구 → 플러그인에 Better BibTeX · Zotmoov 활성
  • 문서\paper-toolkit\tools\KBG-PAPER-A.html을 브라우저로 열면 PLS-SEM 분석기가 뜬다 (예제 데이터 버튼으로 시험)

08문제 해결

증상원인해결
"이 시스템에서 스크립트를 실행할 수 없으므로…"실행 정책명령 앞에 powershell -ExecutionPolicy Bypass -File을 붙였는지 확인. 그래도 막히면 ZIP "차단 해제"(1단계 참고)
한글이 깨져 보임콘솔 코드페이지실행 전 chcp 65001 입력. 스크립트 자체는 UTF-8(BOM)이라 동작에는 영향 없음
"winget 없음"앱 설치 관리자 미설치Microsoft Store → "앱 설치 관리자" 설치 → 재실행. 또는 -SkipWinget 후 프로그램을 직접 설치
"python 없음" / "claude CLI 없음"방금 설치돼 PATH 미반영PowerShell 창을 새로 열고 -SkipWinget으로 재실행
pip 설치 중 빨간 오류빌드 도구 없는 패키지Python 3.12 권장(3.14는 일부 패키지 휠 없음). 실패한 패키지만 pip install 이름으로 재시도
MCP가 "이미 등록됐거나 실패"중복 등록claude mcp list로 확인. 지우고 다시: claude mcp remove kordoc
스킬이 Claude Code에 안 보임재시작 안 함 / 폴더 위치Claude Code 완전 종료 후 재실행. ~\.claude\skills\paper-study\SKILL.md가 있는지 확인
humanize가 에이전트를 못 찾음agents 복사 누락~\.claude\agents\에 .md 7개 있는지 확인, 없으면 ZIP의 agents\에서 복사
ocrmypdf 실행 시 Ghostscript 오류5단계 미완Ghostscript 설치 후 새 터미널
zotero 스킬 "zotero.sqlite 없음"데이터 폴더 위치6단계 경로 확인 참고

09업데이트·제거

업데이트

  • 스킬 묶음: 새 ZIP을 받아 install.ps1 -Force -SkipWinget -SkipPip -SkipMcp
  • 플러그인: Claude Code에서 /plugin marketplace update claude-paper-skills (ARS·deep-research도 같은 방식)
  • 프로그램: winget upgrade --all

제거

  • 스킬: ~\.claude\skills\에서 해당 폴더 삭제, 에이전트는 ~\.claude\agents\에서 .md 삭제
  • 플러그인: /plugin uninstall paper-skills 등
  • MCP: claude mcp remove 이름
  • 프로그램: 설정 → 앱에서 제거 (Zotero 데이터 폴더 ~\Zotero는 남음)
