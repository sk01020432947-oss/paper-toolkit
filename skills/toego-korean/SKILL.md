# 퇴고 — 사람이 쓴 한국어 글 고치기

## 이 스킬의 철칙

**하나. 내용은 건드리지 않는다.**
사실·주장·수치·고유명사·인용·사건의 순서는 한 글자도 바꾸지 않는다. 바꾸는 것은 문체·리듬·길이·순서뿐이다. 글쓴이가 하려던 말이 달라졌다면 퇴고가 아니라 대필이다.

**둘. 쓰는 머리와 고치는 머리를 섞지 않는다.**
새 문장을 지어내 채워 넣지 않는다. 있는 재료로 고친다. 정보가 비어 있으면 채우지 말고 질문으로 돌려준다.

**셋. 큰 것부터 내려간다.**
구조 → 문단 → 문장 → 처음과 끝. 순서를 어기면 나중에 통째로 지울 문단을 열심히 다듬게 된다.

**넷. 최종 결정권은 글쓴이에게 있다.**
고친 곳마다 이유를 밝힌다. 이유를 대지 못하는 수정은 하지 않는다.

---

## Phase 0 — 입력 판정 (건너뛰지 말 것)

작업 시작 시 다음 한 줄을 출력한다.

```
toego-korean — {일반|child} 모드 / 입력 {N}자
```

### 라우팅 확인

먼저 세 가지를 판정하고, 해당하면 즉시 넘긴다.

| 입력 | 보낼 곳 |
|---|---|
| AI가 생성한 글 (사용자가 밝혔거나, 기계적 병렬·불릿 과다·번역투가 뚜렷함) | `humanize-korean` |
| 설교문 | `sermon-toego-revision` |
| 논문을 아직 못 쓴 상태 (기획·목차 단계) | `paper-writing-order` |

AI 글인지 애매하면 묻는다. 넘기지 않고 진행할 경우 한 줄로 근거를 밝힌다.

### 모드 결정

- 사용자가 아이의 글이라고 밝히거나 `--child`를 붙이면 → **child 모드**
- 그 외 → **일반 모드**

child 모드의 차이는 아래 §child 모드 규칙에 있다. 점검 항목 자체는 같다.

### 사전 질문 (한 번만, 최대 두 개)

고치기 전에 반드시 묻는다.

1. **이 글은 누가 읽습니까?** (독자가 정해져야 무엇을 뺄지 정해진다)
2. **분량 제한이 있습니까?**

사용자가 "알아서 해 달라"고 하면 독자를 '일반 성인 독자'로 가정하고 진행하되, 가정했다는 사실을 밝힌다.

---

## Phase 1 — 구조

문장은 아직 건드리지 않는다.

1. **한 문장 요약을 만든다.** 이 글이 하려는 말을 한 문장으로 쓴다. 못 쓰겠으면 그 자체가 첫 번째 진단이다. 사용자에게 되묻는다.
2. **기여하지 않는 문단을 찾는다.** 그 한 문장에 기여하지 않는 문단을 표시한다. 잘 쓴 문단이어도 표시한다. 잘 쓴 문단일수록 위험하다.
3. **순서를 점검한다.** 앞뒤를 바꾸면 나아지는 문단이 있는지 본다. 특히 결론이 뒤에 숨어 있는지 확인한다. 하고 싶은 말은 앞에 온다.
4. **심어 놓고 안 거둔 것을 찾는다.** 앞에서 등장시킨 물건·사람·사건 중 뒤에서 다루지 않은 것을 찾는다. 뒤에서 다루거나 앞에서 뺀다.

이 단계의 산출은 **구조 진단 3줄**이다. 아직 원고를 고치지 않는다.

---

## Phase 2 — 문단

1. 한 문단에 두 가지 이야기가 섞여 있으면 나눈다.
2. 열 줄이 넘는 문단은 나눌 곳을 찾는다.
3. 주장만 있고 사례가 없는 문단을 표시한다. **사례는 지어내지 않는다.** "여기에 겪은 일 하나가 필요합니다"라고 질문으로 돌려준다.

---

## Phase 3 — 문장

한 번에 한 항목씩 훑는다. 여섯 번 통과시킨다.

### 3-1. 길이

한 문장이 60자를 넘으면 검토한다. 긴 문장은 대개 두 개 이상이 붙어 있다.

> 예산 부족으로 인해 일정이 지연되었으며 그로 인해 담당자들이 추가 근무를 하게 되면서 부서 전체의 사기가 저하되는 결과를 낳았다.
> → 예산이 모자라 일정이 밀렸다. 담당자들은 야근을 했다. 부서 분위기가 가라앉았다.

### 3-2. 군더더기

**판별 기준은 하나다. 빼도 뜻이 같으면 뺀다.**

~에 대하여 / ~에 관하여 / ~라고 할 수 있다 / ~하는 것 같다(확신이 있는데 붙인 경우) / 매우 · 정말 · 너무 · 굉장히 · 참으로 / 사실상 · 기본적으로 · 어떻게 보면 · 나름 / ~적인 것

### 3-3. 흐린 낱말

여러 · 일부 · 상당한 · 적절한 · 다양한 · 많은 → 숫자나 장면으로 바꾼다. 숫자를 모르면 지어내지 말고 표시만 한다.

> 상당수의 학생이 어려움을 겪었다 → 서른 명 중 열아홉 명이 문제를 풀지 못했다

### 3-4. 한자어

대신할 우리말이 있으면 바꾼다.

제고하다→높이다 / 도출하다→끌어내다 / 활용하다→쓰다 / 소요되다→걸리다 / 상기하다→떠올리다 / 개진하다→말하다 / 기인하다→비롯되다 / 산재하다→흩어져 있다 / 명시하다→밝히다 / 상이하다→다르다

대신할 우리말이 없으면 둔다. 한자어를 다 없애는 것이 목적이 아니다.

### 3-5. 피동

'~되다', '~어지다', '~에 의해'가 반복되면 능동으로 돌린다.

> 이 계획은 팀에 의해 수립되었고 다음 주에 시행될 예정이다
> → 팀이 이 계획을 세웠다. 다음 주에 시작한다.

행위자가 중요하지 않거나 모를 때는 피동을 남긴다.

### 3-6. 덜어내기 — 감정의 표시

글쓴이의 불안이 특정 기호로 새어 나온다. 이것들을 지운다.

| 지울 것 | 이유 | 대신 |
|---|---|---|
| 느낌표 | 감정을 강요한다 | 장면·구체적 사실·짧은 문장 |
| 부사 (막·팍팍·너무·진짜·엄청) | 동사가 약해서 붙는다 | 동사를 바꾼다 (정말 빨리 걸었다→뛰다시피 했다) |
| 물결표 · 말줄임표 남발 | 자기 말을 스스로 무르게 만든다 | 그냥 끝낸다 |
| 겸손한 변명 | 방어일 뿐이다 | 통째로 삭제 |

겸손한 변명 목록: 글솜씨가 부족하지만 / 제가 잘 몰라서 그런데 / 별거 아니지만 / 이런 얘기 해도 될지 모르겠지만 / 두서없지만

**독자는 글쓴이가 스스로 별거 아니라고 하는 글을 읽지 않는다.**

### 3-7. 비겁한 문장

정하지 않고 넘어간 문장을 찾는다.

> 일장일단이 있다 / 여러 의견이 있을 수 있다 / 경우에 따라 다르다 / ~라고 볼 수도 있다

각각에 대해 사용자에게 묻는다. **정말 모르는 것입니까, 말하기 싫은 것입니까.** 전자면 자료가 필요하고 후자면 결정이 필요하다. 대신 결정해 주지 않는다.

### 3-8. 주도적인 동사

'되었다 / 해졌다 / 어쩔 수 없이 그리 되었다' → '나는 ~했다'로 바꿀 수 있는지 본다. 자기 이야기인데 수동적인 동사가 반복되면 글쓴이가 자기 삶의 구경꾼으로 읽힌다.

### 3-9. 자기 정보

자기 이야기인데 글쓴이가 누구인지 알 수 없으면 표시한다. 한 줄이면 충분하다. **내용을 지어내지 말고 질문으로 돌려준다.** ("여기에 '입사 삼 년째였다' 같은 한 줄이 있으면 독자가 설 자리가 생깁니다.")

---

## Phase 4 — 처음과 끝

### 첫 문장

글 전체에서 가장 좋은 문장을 찾는다. 그것이 지금 첫 문장이 아니면 앞으로 옮길 것을 제안한다. 원래 첫 문단은 지운다.

시작을 새로 잡아야 하면 네 가지 중에서 고른다: 장면 / 어긋나는 말 / 구체적인 질문 / 사실.

피할 시작: 사전 정의("독서란 ~을 뜻한다") / 변명 / 아무 글에나 붙는 큰 말("현대 사회는 급변하고 있다").

### 마지막

1. **마지막 문단을 지워 본다.** 대개 그 앞에서 이미 끝나 있다. 지운 쪽이 나으면 그렇게 제안한다.
2. 교훈("많은 것을 배웠다", "앞으로 열심히 하겠다")·감사·요약으로 끝나면 바꾼다.
3. 마지막 문장을 스무 자 안쪽으로 줄인다.
4. 대안: 장면으로 끝내기 / 첫 문단의 것을 다시 부르되 의미를 바꾸기 / 자기 언어로 다시 정의하기.

---

## Phase 5 — 리듬 점검 (소리 내어 읽기 대체)

사람은 소리 내어 읽어 걸리는 곳을 찾는다. 이 스킬은 대신 다음을 계산한다.

1. 문장 길이를 순서대로 나열한다. 비슷한 길이가 다섯 문장 이상 이어지면 표시한다. 리듬이 평평하면 읽는 사람이 지친다.
2. 같은 종결어미('~했다' 등)가 네 번 이상 연속되면 표시한다.
3. 같은 낱말이 한 문단에 세 번 이상 나오면 표시한다.
4. **마지막에 반드시 사용자에게 권한다.** "고친 글을 소리 내어 두 번 읽어 보십시오. 입이 걸리는 곳이 남은 문제입니다." 이 문장은 생략하지 않는다.

---

## 산출물

다음 네 가지를 이 순서로 낸다.

### 1. 진단 3줄
구조·문단·문장 각 한 줄. 가장 큰 문제 하나씩만.

### 2. 수정본
고친 글 전문. 설명 없이 글만.

### 3. 변경 대조표
고친 곳만 표로. 열 개가 넘으면 유형별로 묶고 대표 사례만 보인다.

| 원문 | 수정 | 이유 |
|---|---|---|
| 이 문제에 대하여 기본적으로 매우 신중한 접근이 필요하다고 할 수 있다 | 이 문제는 신중하게 다뤄야 한다 | 군더더기 |

### 4. 남은 버릇 한 개
글쓴이가 가장 많이 반복한 버릇 하나만 짚는다. 여러 개를 짚으면 하나도 안 고쳐진다.

> 이번 글에서 '~것 같다'가 아홉 번 나왔습니다. 다음 글에서는 이것 하나만 보십시오.

### 분량 보고
글자 수 변화를 한 줄로 적는다. `1,840자 → 1,470자 (20% 감소)`

## child 모드 규칙

아이의 글을 다룰 때 달라지는 것.

**고쳐 주지 않는다. 질문으로 돌려준다.**
어른이 고친 문장은 아이의 문장이 아니다. 대신 이렇게 한다.

- "이 부분 더 듣고 싶은데, 그때 어땠어?" → 아이가 답하면서 스스로 문장을 만든다.
- "여기서 무슨 소리가 났어?" → 묘사가 나온다.
- "'되었다' 말고 '나는 ~했다'로 바꿔 볼래?" → 주어를 찾는다.

**한 번에 한 가지만 짚는다.** 세 가지를 지적하면 아이는 쓰기를 그만둔다.

**먼저 좋은 곳을 구체적으로 말한다.** "잘 썼어"가 아니라 "세 번째 줄에서 그 장면이 눈에 보였어".

**맞춤법은 마지막에, 그것도 두 개까지만.**

**적용할 항목은 셋뿐이다.** 3-1(길이), 3-6(느낌표·부사), Phase 4(마무리에서 교훈 빼기). 나머지는 건드리지 않는다.

**산출물도 다르다.** 대조표를 만들지 않는다. 질문 목록 3개와 칭찬 1개만 낸다.

---

## 하지 않는 것

- 내용 추가. 사례·수치·인용을 지어내지 않는다.
- 글쓴이의 목소리 지우기. 특이한 표현이 그 사람 문체일 수 있다. 반복되면 문체로 보고 남긴다.
- 한 번에 모든 것 고치기. 사용자가 항목을 지정하면 그것만 한다.
- 점수 매기기. 등급이나 점수를 내지 않는다.
- 잘 쓴 문장 칭찬 생략. 최소 한 곳은 어디가 왜 좋은지 짚는다. 글쓴이는 자기 강점을 모른다.

## 참고

이 스킬의 점검 항목은 다음에서 왔다.

- **유시민** — 나쁜 글 고치는 여섯 가지 (소리 내어 읽기·짧게·군더더기·흐린 낱말·한자어·피동)
- **임경선** — 들뜸 없는 글쓰기 (느낌표·부사·겸손한 변명, 감정 빌드업)
- **양다솔** — 사소한 습관 (물결표)
- **최혜진** — 주도적이지 않은 동사, 자기 정보 생략, 떡밥 회수
- **김연수** — 비겁한 문장, 글쓰기가 곧 결정
- **이다혜** — 마무리, 글의 경제성, 자기 언어로 다시 정의하기
- **하완** — 초고에서 절제하지 않기, 인과 관계
- **은유** — 첫 문장은 나중에 정해진다
